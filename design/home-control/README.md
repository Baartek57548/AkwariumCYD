# Marka Home Control

Znak łączy obrys domu z centralnym węzłem komunikacyjnym. Gradient aqua–indigo odróżnia Home Control od turkusowego znaku AquaCYD Service, zachowując wspólne pochodzenie produktów.

Źródłem wektorowym jest `home-control-mark.svg`, a odpowiednik renderowany bez zasobu bitmapowego znajduje się w pakiecie `packages/design_system`. Eksporty sklepowe należy generować z SVG w pipeline projektu graficznego i zatwierdzić przed publikacją produkcyjną.
