# Backgrounds

Default aquarium background:

```text
aquarium-rockscape-320x240.rgb565
```

Companion files:

```text
aquarium-rockscape-320x240.jpg
aquarium-rockscape-original.jpg
```

The original source image is `320x280` and contains black bars. The screen-ready
variant crops the visible aquarium area and scales it to `320x240`, matching the
landscape CYD display.

RGB565 file details:

```text
width=320
height=240
format=rgb565
byte_order=little-endian
bytes=153600
```
