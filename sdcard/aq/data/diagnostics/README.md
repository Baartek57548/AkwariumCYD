# Diagnostics

Store boot reports, heap snapshots, and SD health information here.

Suggested files:

```text
boot_000001.txt
boot_last.txt
heap_YYYY-MM-DD.csv
heap_last.csv
sd_YYYY-MM-DD.txt
sd_health.txt
crash_marker.txt
```

Heap CSV should include internal RAM, DMA-capable RAM, and largest free block.
