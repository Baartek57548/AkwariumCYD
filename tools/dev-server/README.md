# Lokalny backend DEV

Uruchomienie:

```powershell
npm run dev:web
```

Panel jest dostępny pod `http://127.0.0.1:8000/`. PIN administratora w symulatorze jest zgodny z firmware i wynosi `1234`.

Symulator utrzymuje telemetrię, historię, logi, ustawienia i sesje klientów wyłącznie w RAM procesu. Nie zapisuje danych pomiarowych w `web`, `sdcard` ani na fizycznej karcie SD.
