# Archived repository state

This directory preserves files moved out of the active WeMos and ESP32-S3
firmware repository on 2026-10-02. It includes the former CYD firmware, web and
mobile applications, supporting documentation, build scripts, and the previous
root project configuration.

The archived paths mirror their former repository paths wherever possible.
Nothing here is part of the active PlatformIO build. To restore an archived
project, move its required files back to the repository root and restore the
corresponding archived `platformio.ini` and `README.md`.
