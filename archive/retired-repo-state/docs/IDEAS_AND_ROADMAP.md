# Roadmapa AquaCYD

## Najbliższe

- 72-godzinny HIL CYD + WeMos z aktywnym WWW i cyklicznym zapisem ustawień;
- pomiar czasu odpowiedzi HTTP, opóźnień UART, sterty i high-water mark stosów;
- regresja jasnego motywu i dolnej nawigacji po każdym zimnym starcie;
- automatyczne zrzuty widoku telefonu 360×800 i pulpitu 1440×900;
- procedura odtworzenia karty SD z podpisanego pakietu WWW.

## Później

- eksport konfiguracji bez sekretów i kontrolowany import z walidacją;
- wykresy o ograniczonej liczbie próbek, bez dynamicznego wzrostu pamięci;
- diagnostyka jakości UART i liczników odrzuconych ramek;
- dostęp zdalny wyłącznie przez odseparowaną bramę HTTPS, bez wystawiania CYD.
