# Obudowa AquaBox — modele do druku

Pliki STL obudowy przeniesione z historycznego projektu CAD do
`archive/retired-repo-state/AquaBox/Aquabox/`:

- `OBUDOWA PODSTAWA.STL` — dolna część obudowy;
- `OBUDOWA POKRYWA.STL` — górna pokrywa.

Modele mają odpowiadające im źródła SolidWorks w archiwum. To eksporty gotowe
do otwarcia w slicerze, ale ich dopasowanie do obecnej konfiguracji elektroniki
nie zostało ponownie sprawdzone. Przed drukiem zweryfikuj wymiary, tolerancje,
otwory i rozmieszczenie elementów względem posiadanego WeMos oraz zasilacza.

Archiwalna notatka konstrukcyjna sugeruje PETG/ASA, warstwę 0,20 mm, co
najmniej 4 obrysy i 25% wypełnienia. To punkt startowy, nie zatwierdzony profil
drukarki ani certyfikacja obudowy. Obudowa zawiera elementy zasilania sieciowego;
wydruk 3D sam w sobie nie zapewnia izolacji, odporności ogniowej ani ochrony
przed wodą.
